# TEDリスニング再生

TED トークを、1文ずつ字幕つきで繰り返し聴くためのページ。上の「トーク」で切り替える。

- Tim Urban「Inside the Mind of a Master Procrastinator」（5区間）
- Julian Treasure「How to speak so that people want to listen」（6区間・2026-10-24 追加。アカデミック・ライティングの TED 課題で選んだもの）
tatsuki の英語リスニング練習用（法政大学2年・2026秋）。

**https://tatsuki816.github.io/ted-listening/**

## できること

- 文をタップするとそこから再生。今の文が蛍光ペンで光る
- 繰り返し：流す／1文／A–B（範囲）／区間まるごと
- 字幕：なし（英文をぼかす）／英／日／英日。「今の文を見る」で1文だけ開ける
- 速さは −／＋ で 0.5〜1.5倍を 0.05 刻み（0.5／0.75／1／1.25 のボタンもある）。繰り返しの間は −／＋ で 0〜10秒を 0.5秒刻み、なし、自動（聞いた長さ＋0.8秒）
- **辞書**（2026-10-24）：「辞書」を押してから英文の単語をタップすると、下に意味が出る。再生位置は動かない。窓をタップすると閉じる
- 間の途中は再生ボタンの横に残り秒数が出る（止まったのか間なのか分かるように。2026-10-24）
- **シャドーイングの4段階**（2026-10-13 追加）。いきなり音にかぶせると聞き取れず意味も追えないので、意味を先に入れてから音に近づける
  - ① 意味：英日の字幕で1文ずつ止まる
  - ② リピート：3〜6語のかたまりごとに止まり、その間に言い返す。今のかたまりが光る
  - ③ 重ねる：英文を見ながら1文を繰り返し、音と同時に言う
  - ④ シャドー：字幕なしで1文を繰り返し、追いかけて言う
  - 段階は設定のまとめ押し。押した後に速さなどを手で変えると段階の印は外れる
- 繰り返しの「止めて進む」：区切り（文／かたまり）ごとに止まり、間のあと次へ進む
- **1回開けば圏外でも動く**（Service Worker が5区間ぶんの音声を貯める。右上に「圏外OK」が出たら完了）
- iPhone は Safari の共有 → ホーム画面に追加 でアプリのように使える

## 構成

| ファイル | 役割 |
|---|---|
| `雛形.html` | ページの本体。`__DATA__` に字幕が入る（`{トーク名: {話者, 題, 年, wpm, 出典, 音声, 区間}}`） |
| `訳.py` | Tim Urban の132文の日本語訳 |
| `トーク/treasure/` | Julian Treasure の文ごとのデータ・単語の時刻・訳（`訳.py`） |
| `トーク準備.py` | 新しいトークの下ごしらえ。英文を文に割り、全体の音声で時刻を合わせ、区間ごとに音声を切る |
| `組み立て.py` | 雛形に字幕・かたまり・辞書を流し込んで `index.html` を作る。トークはここの `トーク` に並べる |
| `ズレ検査.py` | 公開している区間の音声を whisper にかけ直し、字幕の開始と実際の音のずれを測る。`--直す` で遅れている文の開始を前へ寄せる。**トークを足したら必ず通す**（2026-10-24 時点で両トークとも 0.3秒を超えて遅れる文は0） |
| `辞書.py` | ページに出る全単語の意味を EJDict（CC0）から引いて `辞書.json` を書く。無い語・意味がずれる語は `手書き` に足す |
| `かたまり.py` | 1文を言い返せる長さのかたまりに区切り、時刻を付けて `かたまり.json` を書く。`--見る` で区切りを全部表示 |
| `単語の時刻/` | whisper の単語ごとの時刻（かたまり.py の下ごしらえ）。音声を切り直したら消して回し直す |
| `sw.js` | 圏外対応。音声は Range 要求に 206 で返す（Safari の `<audio>` はこれが無いと再生できない） |
| `audio/1〜5.mp3` | Tim Urban の区間ごとの音声 |
| `audio/treasure/1〜6.mp3` | Julian Treasure の区間ごとの音声 |

字幕の時刻と英文は Obsidian の vault の `法政大学2年/英語ライティング/リスニング/データ/` から読む（書き取りツール `書き取り.py` と同じデータ）。

## トークを足すとき

1. `元データ_<名>/` に材料を置く（gitignore 済み）
   - `全体.mp3`：TED のページの HTML にある `py.tedcdn.com/...mp4` を curl で取って ffmpeg で音声だけ抜く。YouTube は yt-dlp が 403、ted.com を yt-dlp に渡すと落ちた（2026-10-24）
   - `transcript.json`：`/transcript?language=en` のページの `__NEXT_DATA__` の `transcriptData.translation.paragraphs[].cues`
2. `トーク準備.py` の `区間の割り方` に区間の切れ目を書いて、`~/音声入力/.venv/bin/python3 トーク準備.py <名>` で確認、`--書く` で書く
3. `トーク/<名>/訳.py` に日本語訳を書く（区間ごとに文の数をそろえる）
4. `ズレ検査.py <名>` でずれを測り、遅れている文があれば `--直す`
5. `かたまり.py` と `組み立て.py` の `トーク` に足して、`かたまり.py` → `辞書.py` → `組み立て.py` の順に回す。`辞書.py` が「見つからない」と出した語は `手書き` に足す
6. 下の「直すとき」の3〜4

## 直すとき

1. `雛形.html` か `訳.py` を直す（英文や音声を直したら `~/音声入力/.venv/bin/python3 かたまり.py` と `python3 辞書.py` も回す）
2. `python3 組み立て.py`
3. 中身を変えたら `sw.js` と `雛形.html` の `キャッシュ名` の `v1` を上げる（上げないと古い版がスマホに残る）
4. commit して push。GitHub Pages が1分ほどで反映する

push は個人アカウント `tatsuki816` の HTTPS で行う（この Mac の ssh 鍵は別アカウントで名乗るため）。

## やってはいけないこと（実際に踏んだもの）

- **`clients.claim()` を入れない。** 開いている途中のページを SW が握ると、同じ音声ファイルの最初の要求は
  ネット・残りは SW が作った応答、と届け主が途中で入れ替わり、`MEDIA_ERR_NETWORK`（エラー2）で止まる。
  2026-09-24 に本番の初回表示で発生。手元の試験は2回目以降の読み込みしか見ていなかったので気づけなかった。
  **試すときは SW とキャッシュを消した「初回」から始める**
- **音声を丸ごと 200 で返さない。** Safari の `<audio>` は Range 付きで要求するので、切り出して 206 で返す
- **ループの的を「今の文」にしない。** 文の境目の先読み（0.05秒）が戻し（0.03秒）より先に効き、戻す前に
  次の文へ乗り換えて素通りする。ループ中の文は `固定` に持つ
- **境目の判定を `requestAnimationFrame` だけに頼らない。** iPhone で画面を消すと止まる。
  `timeupdate` と 0.1秒タイマーからも呼んでいる
- **戻した直後の `currentTime` を信じない。** iPhone の Safari は位置を指定してから読み込みが終わるまで古い位置を返す。
  すぐ境目を見ると「文の終わりを越えた」ともう一度止まり、1文ループで間が2回分空いた（2026-10-13 本人報告）。
  戻した・飛んだ後は `着くまで待つ` で本当に着くまで見張りを止める。Chromium では再現しないので、
  試すときは `currentTime` の getter を差し替えて「400ms 古い位置を返す」まねをする
- 殻のキャッシュ名（`ted-shell-vN`）は直すたびに上げる。音声（`ted-audio-vN`）は音声が変わらない限り上げない
- GitHub Pages は `max-age=600`。直した直後の10分は古い版が返ることがある
